# Dim Chukwuebuka Samuel: Portfolio

Personal portfolio of Dim Chukwuebuka Samuel, a Lagos-based web developer, AI automation engineer and motion designer (ThonLabs).

**Live site:** https://samuel-portfolio-liard.vercel.app

## What's inside

- `index.html`: the full single-page site (HTML, CSS and JavaScript, no build step)
- `reel.mp4`, `poster.webp`: 720p motion showreel (one file, shared by every video on the page) and its poster frame
- `sp.webp`, `lg.webp`: n8n workflow screenshots (StorePulse reporting and lead generation)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Static site. Import this repo into Vercel with no framework and no build command.
